Before you send the RFQ

An insert code or a short description is enough to start. Add quantity, workpiece material and packing requirements when available.

MOQ

Turning inserts start from 10 pieces per model (one box). PCD, CBN and cermet MOQs are confirmed per model. Standard solid carbide end mills start from 1 pc per model. Private label packing starts from 2,000 pieces per model; custom tools are confirmed by drawing and quantity.

Packing

Neutral and private label packing can be discussed; confirm the format, quantity and cost in your quote.
