How to use this chart

  1. Read the code off the box or the insert (worn off? Use our free photo identification: /insert-identification).
  2. Match the full code here — same shape letters but a different size pair (for example 09 vs 12) is a different insert and will not seat in the same holder pocket.
  3. Check the hole diameter against your holder's pin/clamp if you are switching brands; the IC and thickness decide the pocket, the hole decides the clamping fit.
  4. Nose radius is the last pair of digits: 04 = 0.4 mm (finishing, lighter cuts), 08 = 0.8 mm (general purpose), 12 = 1.2 mm (heavy, rigid setups).

Dimensions are nominal ISO values; tolerance class (the third letter of the code) sets the allowed variation — see our code-decoding guide: /blog/how-to-read-insert-code.
