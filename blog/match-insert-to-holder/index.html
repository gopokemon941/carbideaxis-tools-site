How to Match a Turning Insert to Its Tool Holder

Three matches decide whether an insert seats correctly: the shape letter, the size, and the rake system. Fail one and the grade cannot save it.

Have a turning insert code or holder photo?Check my turning insert

A turning insert fits its holder when three things match at once: the shape letter, the size (inscribed circle, thickness and fixing hole), and the rake system — negative inserts (N, 0° clearance) need a negative holder, positive inserts (C, 7° clearance) need a positive holder. Read the holder code the same way you read the insert code: its five letters name the clamping system, the insert shape, the approach angle, the clearance and the hand. If any one of the three matches fails, the insert will not seat correctly, however good the grade is.

Two things about this table. First, the holder names are families, not complete order codes: a full holder code adds the hand (R or L), the shank size and the insert size, for example PCLNR 2525M12. Second, the second letter of the holder code always repeats the insert shape — C for CNMG and CCMT, W for WNMG, T for TNMG, D for DNMG and DCMT, S for SNMG, V for VNMG. If the second letters do not agree, the insert does not belong in that holder, and no other match can rescue it. Take PCLNR 2525M12 — the most common holder for a CNMG120408 — and read it left to right:

5 — handRRight-hand holder

The same logic covers the positive family. SCLCR is the screw-lock holder for a CCMT insert: S for screw lock, C for the 80° shape, L for 95°, C for 7° clearance, R for right-hand. SDJCR is the same idea for a DCMT insert: D for the 55° shape, J for a 93° approach angle. Once you can read the five letters, you can check a holder you already own without a catalogue — and you can spot a wrong holder before it is ordered.

Boring bars follow the same five letters with a shank prefix in front, for example S12S-SCLCR-09: the S12S part names the steel bar and its diameter, and the SCLCR part is the same holder code you would read on an external holder. The matching rules below apply to bars exactly as they do to external holders.

The three matches that must all pass

1. Shape. The first letter of the insert code and the second letter of the holder code must be the same letter: C with C, D with D, W with W, S with S, T with T, V with V. A DNMG (55°) will not seat in a CNMG holder even though both are negative inserts — the pocket is cut for a different corner angle. This is the same lesson as changing shape in DNMG vs CNMG: shape is a holder decision, not just an insert decision.

2. Size. The inscribed circle, thickness and fixing hole must match the pocket. CNMG120408 and CNMG120404 share the same body — 12.7 mm inscribed circle, 4.76 mm thick, 5.16 mm hole — so they fit the same holder and only the nose radius changes. But CNMG120408 and CCMT09T308 do not: 12.7 mm against 9.525 mm inscribed circle, different thickness, different hole. The size pair in the code is the size: 09 against 12 is a different insert and a different pocket, even when the shape letters agree. Check the hole too when you change brands — the inscribed circle and thickness decide the pocket, the hole decides whether the pin or screw clamps correctly. Full dimensions for every code in this article are in the insert size chart.

3. Rake system. Negative and positive inserts need different holders, as explained in negative vs positive inserts. The fourth letter of the holder code tells you which system it is: N means the holder is built for a 0°-clearance insert, C means it is built for a 7°-clearance insert. A CCMT will not seat correctly in a PCLN holder, and a CNMG will not seat correctly in an SCLCR holder — the pockets, clamps and screw positions are different. Changing rake therefore means changing the holder system, and the holder cost belongs in the decision from the start.

If all three pass, the insert seats. If any one fails, stop — a trial in the wrong seat proves nothing about the insert, and a forced fit risks the holder as well as the edge.

Right-hand, left-hand or neutral — does the hand matter?

Yes, and it is the easiest of the three to get wrong by accident. The fifth letter of the holder code is the hand: R is right-hand, L is left-hand, N is neutral. Most general turning is done with a right-hand holder, which is why PCLNR and SCLCR are the codes you will see most often. A left-hand holder presents the insert from the other side, for work that a right-hand holder cannot reach — typically turning toward a shoulder from the opposite direction, or a mirrored setup.

The practical rule is simple: match the hand to the holder you are replacing, or to the direction the tool will travel. If you are unsure which hand you have, photograph the marking on the holder shank — the five-letter code is stamped there — and send it with the insert code. A holder bought in the wrong hand is not a small mistake: the edge faces the wrong way and the holder cannot be used for the job it was bought for.

Shank size and machine fit

The numbers after the letters name the shank: 2525 means a 25 mm × 25 mm square shank, 2020 means 20 mm × 20 mm, 1616 means 16 mm × 16 mm. The shank must fit your turret or toolpost — a 25 mm holder does not fit a 20 mm slot, and a holder that is too small for the turret loses the rigidity the insert was chosen for. There is no universal right size: it depends on your machine, so the shank is a machine question, not an insert question.

Two checks before you order inserts for a holder you have not used in a while: confirm the shank size stamped on the holder, and confirm the insert size digit at the end of the holder code — 12 means the holder takes 12-size inserts (CNMG12xx), 09 means 09-size (CCMT09T3xx), 06 means 06-size (CCMT06xx). The size digit is the fastest cross-check in the whole system: if it does not match the size pair in your insert code, the holder is for a different insert.

Can one holder take two insert shapes?

No — one holder, one shape. The pocket is cut for a single corner angle, so a CNMG holder cannot take a WNMG, and a CCMT holder cannot take a DCMT, even though both pairs look similar at a glance. What one holder *can* take is the same code in different nose radii, chipbreakers and grade groups: CNMG120404 and CNMG120408 share a holder, and so do CCMT09T304 and CCMT09T308. That is why the nose-radius comparison in CNMG120408 vs CNMG120404 needs no holder change to trial — the body is identical and only the corner changes.

The same rule applies across brands. The ISO code is a shared language: a CNMG120408 from any maker seats in a PCLN holder made by any maker, provided the code is complete and correct. What differs between makers is the chipbreaker and the grade behind the code — which is why we confirm the chipbreaker manually for your material and operation before quoting, rather than assuming two inserts with the same code will cut identically. The shape-by-shape economics of switching within the negative family are covered in CNMG vs WNMG.

What about boring bars?

The same three matches apply, with one extra constraint: the bar has to fit the bore. Positive inserts dominate boring work for a reason — a CCMT or DCMT in a screw-lock bar cuts with lower force, which is what a long, slender bar needs — and the bar diameter limits the insert size you can use. A small bore takes a small bar, and a small bar takes a small insert: CCMT060204 exists precisely for that case, where a 09-size insert is too large for the bar that fits the hole.

Read the bar the same way: the code after the shank prefix is the holder code, so S12S-SCLCR-09 tells you the bar takes a CCMT09-size insert in a screw-lock seat. If the marking is worn off, photograph the bar from the side and from above, with the insert still seated if you have one, and we will identify it from the photos.

A short checklist before you order

  • Shape letter of the insert matches the second letter of the holder code
  • Size pair matches: same inscribed circle, thickness and hole — check the size chart
  • Rake system matches: N insert with an N holder, C insert with a C holder
  • Hand matches the direction you will cut (R in most shops)
  • Shank size fits your turret or toolpost, and the holder's size digit matches your insert code
  • Nose radius and chipbreaker chosen for the operation, not just the holder — the radius comparison is in CNMG120408 vs CNMG120404, and the cost of the edges is in the cost-per-edge calculator

If any box is unchecked, send the codes or the photos first. A two-minute check before ordering is cheaper than a box of inserts that does not seat — and cheaper still than a holder bought for the wrong insert.

FAQ

How do I know which holder my insert fits?

Match three things: the shape letter (first letter of the insert code = second letter of the holder code), the size (inscribed circle, thickness and hole), and the rake system (N insert with an N holder, C insert with a C holder). For our stocked range, CNMG fits PCLN- or MCLN-type holders, WNMG fits MWLN-type, TNMG fits PTGN-type, DNMG fits PDJN-type, SNMG fits PSBN-type, VNMG fits PVJN-type, CCMT fits SCLC-type and DCMT fits SDJC-type.

What does PCLNR 2525M12 mean?

P = lever lock, C = 80° rhombic insert, L = 95° approach angle, N = 0° clearance (negative holder), R = right-hand, 2525 = 25 mm × 25 mm shank, M12 = shank length code M and insert size 12 (CNMG12xx). The same five-letter logic reads every holder code in this article.

Can a CNMG insert fit in a CCMT holder?

No. CNMG is a negative insert (0° clearance, double-sided) and CCMT is a positive insert (7° clearance, single-sided); their holders have different pockets, clamps and screw positions, and the two examples are different sizes as well (12.7 mm against 9.525 mm inscribed circle). Changing rake means changing the holder system.

Can CNMG120404 and CNMG120408 share the same holder?

Yes. Both are CNMG1204 size — 12.7 mm inscribed circle, 4.76 mm thick, 5.16 mm hole — so both seat in the same CNMG12 holder. Only the nose radius differs (0.4 mm against 0.8 mm), so you can trial the other radius without changing the holder.

Do WNMG and CNMG use the same holder?

No, even though both are negative inserts with an 80° corner. WNMG fits MWLN-type holders and CNMG fits PCLN- or MCLN-type holders; the pocket shape is different because WNMG is a trigon and CNMG is a rhombic insert. WNMG gives 6 usable edges against CNMG's 4, but only in its own holder — see CNMG vs WNMG.

What is the difference between PCLN and MCLN holders?

Both take CNMG inserts; the first letter is the clamping system. P means lever lock and M means wedge clamp. The wedge clamp generally holds the insert more rigidly for heavier cuts, while the lever lock is the more common general-purpose arrangement. Either seats the same CNMG1204 insert.

How do I read a boring bar code?

The code after the shank prefix is the holder code, read the same way: for example, in S12S-SCLCR-09, the SCLCR part means a screw-lock holder for a CCMT insert, and 09 is the insert size. Match the shape, size and rake system exactly as for an external holder, and check that the bar diameter fits the bore.

What if the holder marking is worn off?

Photograph the holder from the side and from above, with the insert seated if you still have one, and send the photos with the insert code. We identify the holder family from the pocket shape, clamp type and insert size, and confirm the match within 1 working day through our photo identification service.

Can I use the same holder for inserts from different brands?

Yes, if the ISO code is complete and identical — the code is a shared standard, so a CNMG120408 from any maker seats in a PCLN holder from any maker. What differs between brands is the chipbreaker and the grade, which is why we confirm the chipbreaker manually for your material and operation before quoting, and recommend a scored 10-piece trial rather than assuming equal performance.
