How to Read a Carbide Insert Code: CNMG120408 Decoded Letter by Letter

CNMG120408 means: an 80° rhombic insert, 0° clearance, M tolerance class, hole with a double-sided chipbreaker, 12.7 mm inscribed circle, 4.76 mm thick, 0.8 mm nose radius. Clearance letters worth memorising: N = 0°, B = 5°, C = 7°, P = 11°. A positive letter (B/C/P) means a single-sided insert for lower cutting force; N means both faces can be used but needs a negative-rake holder.

Here is the full code, position by position, using CNMG120408 as the worked example.

Position 1 — Shape (C)

The first letter is the insert shape: - C = rhombic (diamond), 80° corner angle - D = rhombic, 55° - S = square, 90° - T = triangular, 60° - V = rhombic, 35° - W = trigon, 80°

Shape decides rigidity and access. The 80° C-corner is the strongest common turning corner; the 35° V-corner reaches into profiles the others cannot. This is also the first check in identification: count the corners and estimate the angle, and you have already narrowed the code to one or two letters.

Position 2 — Clearance angle (N)

The second letter is the relief (clearance) angle: - N = 0° — a "negative" insert. Both faces can be used, so a CNMG offers 4 usable edges, but it needs a negative-rake holder and more machine power. - B / C / P and others (5°, 7°, 11°…) — "positive" inserts, single-sided, lower cutting force, common in small lathes and boring bars (for example CCMT).

Negative vs positive is not a quality ranking; it is a machine-and-job fit question.

Position 3 — Tolerance class (M)

The third letter states the manufacturing tolerance class of the insert itself: - G class = precision-ground, tighter tolerances, higher price — chosen for finishing and for boring, where size repeatability matters most. - M class = standard as-sintered/periphery-ground range used for most general turning. Note that M-class limits are size-dependent (for example, inscribed-circle tolerance roughly ±0.08–0.20 mm across common sizes), which is why two "identical" M-class inserts from different batches can measure slightly differently.

If your process swaps inserts without re-offsetting, this letter matters more than the brand printed on the box.

Position 4 — Fixing and chipbreaker type (G)

The fourth letter describes the fixing hole and chipbreaker configuration: - G = cylindrical fixing hole, chipbreaker on both faces (typical for double-sided negative inserts like CNMG). - A = fixing hole, no chipbreaker. - T = fixing hole with countersink, chipbreaker on one face (typical for positive inserts like CCMT09T304).

The digits — Size, thickness, nose radius

After the four letters come three number pairs: - 12 = size code. For a CNMG this corresponds to a 12.7 mm inscribed circle (the standard "12" size; a WNMG "08" is 9.525 mm). - 04 = thickness code: 4.76 mm. - 08 = nose radius: 0.8 mm (04 = 0.4 mm, 12 = 1.2 mm).

Nose radius is the digit buyers most often order wrong: a larger radius is stronger and feeds faster but needs more power and can chatter on slim parts; a smaller radius finishes better at light depths.

What the ISO code does NOT tell you

Everything after CNMG120408 — the two-letter suffix (such as -MA, -PM, -TM) and the grade name — is manufacturer-specific. The suffix is the chipbreaker geometry, the grade is the carbide substrate plus coating recipe. There is no ISO table that converts one maker's grade into another's; anyone who gives you a conversion chart is giving you a starting point for a trial, not an equivalence. This is exactly why the same CNMG120408 from two suppliers can behave like two different tools: the ISO part is identical, the chipbreaker and grade are not.

When you ask for a quote, quote the full string: ISO code + chipbreaker suffix + grade (or the material group it should cover: P steel, M stainless, K cast iron). Quotes you receive back are only comparable when all three parts match your request.

FAQ

Can I identify an insert from the code alone if the markings are worn off? The code is what is worn off — identification then works in reverse: measure the inscribed circle and thickness with a caliper, identify the shape and corner angle, and check the chipbreaker form. Our free photo identification service (/insert-identification) does exactly this from three photos.

Is a G-class insert always better than M-class? No. G costs more because it is ground to tighter tolerance. For roughing and most general turning, M is the rational choice; for finishing passes and boring where you swap edges without touching offsets, G earns its price.

My current insert is from a major brand. Can a different maker's same ISO code replace it? Geometrically yes — it will fit the same holder. Cutting behaviour depends on the chipbreaker and grade, which are maker-specific, so treat the first order as a structured trial: same workpiece, same parameters, count parts per edge.

Can I swap a CNMG for a WNMG? Only with a holder check. WNMG gives 6 usable edges against CNMG's 4, which is its whole economic point, but it needs its own holder seat. We compare the two, including holder fit, in our CNMG vs WNMG guide (/blog/cnmg-vs-wnmg).

What does the suffix after the code, like -MA or -PM, mean? It is the manufacturer's chipbreaker geometry — maker-specific, not an ISO position. Two inserts with the same ISO code and different suffixes can cut very differently, so never drop the suffix from a quote request.

Does the ISO code tell me the grade or coating? No. The grade name after the code is the maker's substrate-plus-coating recipe, and there is no ISO table converting one maker's grade into another's. A conversion chart is only a starting point for a trial.

Why do two suppliers' CNMG120408 inserts perform differently? Because the ISO part is identical and the maker-specific part is not: chipbreaker geometry and grade decide chip control, edge strength and wear. Same code, same holder, different cutting behaviour — which is why the first order should be a scored trial, not a price comparison.

What should I put in a quote request? The full string: ISO code + chipbreaker suffix + grade, or the material group it must cover (P steel, M stainless, K cast iron). Quotes are only comparable when all three parts match your request.

How do I read a code I have never seen? Read it position by position from the table above: shape, clearance, tolerance, fixing/chipbreaker, size, thickness, nose radius. If the markings are worn off, measure the inscribed circle and thickness and use our photo identification service (/insert-identification) instead of guessing.
