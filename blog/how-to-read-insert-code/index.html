How to Read a Carbide Insert Code: CNMG120408 Decoded Letter by Letter

CNMG120408 means: an 80° rhombic insert, 0° clearance, M tolerance class, hole with a double-sided chipbreaker, 12.7 mm inscribed circle, 4.76 mm thick, 0.8 mm nose radius. The ISO part defines the nominal fit dimensions; the chipbreaker suffix and grade after it decide how it cuts — so always quote all three.

Clearance letters worth memorising: N = 0°, B = 5°, C = 7°, P = 11°. A positive letter (B/C/P) means a single-sided insert for lower cutting force; N means both faces can be used but needs a negative-rake holder.

Here is the full code, position by position, using CNMG120408 as the worked example.

Position 1 — Shape (C)

The first letter is the insert shape: - C = rhombic (diamond), 80° corner angle - D = rhombic, 55° - S = square, 90° - T = triangular, 60° - V = rhombic, 35° - W = trigon, 80°

Shape decides rigidity and access. The 80° C-corner is the strongest common turning corner; the 35° V-corner reaches into profiles the others cannot. This is also the first check in identification: count the corners and estimate the angle, and you have already narrowed the code to one or two letters.

Position 2 — Clearance angle (N)

The second letter is the relief (clearance) angle: - N = 0° — a "negative" insert. Both faces can be used, so a CNMG offers 4 usable edges, but it needs a negative-rake holder and more machine power. - B / C / P and others (5°, 7°, 11°…) — "positive" inserts, single-sided, lower cutting force, common in small lathes and boring bars (for example CCMT).

Negative vs positive is not a quality ranking; it is a machine-and-job fit question.

Position 3 — Tolerance class (M)

The third letter states the manufacturing tolerance class of the insert itself: - G class = precision-ground, tighter tolerances, higher price — chosen for finishing and for boring, where size repeatability matters most. - M class = standard as-sintered/periphery-ground range used for most general turning. Note that M-class limits are size-dependent (for example, inscribed-circle tolerance roughly ±0.08–0.20 mm across common sizes), which is why two "identical" M-class inserts from different batches can measure slightly differently.

If your process swaps inserts without re-offsetting, this letter matters more than the brand printed on the box.

Position 4 — Fixing and chipbreaker type (G)

The fourth letter describes the fixing hole and chipbreaker configuration: - G = cylindrical fixing hole, chipbreaker on both faces (typical for double-sided negative inserts like CNMG). - A = fixing hole, no chipbreaker. - T = fixing hole with countersink, chipbreaker on one face (typical for positive inserts like CCMT09T304).

The digits — Size, thickness, nose radius

After the four letters come three number pairs: - 12 = size code. For a CNMG this corresponds to a 12.7 mm inscribed circle (the standard "12" size; a WNMG "08" is 12.7 mm). - 04 = thickness code: 4.76 mm. - 08 = nose radius: 0.8 mm (04 = 0.4 mm, 12 = 1.2 mm).

Nose radius is the digit buyers most often order wrong: a larger radius is stronger and feeds faster but needs more power and can chatter on slim parts; a smaller radius finishes better at light depths.

No box? Work backwards from the insert itself

  1. Measure. With calipers, measure the inscribed circle (across the flats of the shape) and the thickness. Match both against the size and thickness tables above — together they fix the size and thickness digits.
  2. Count the corners. The corner angle gives the shape letter: 80° rhombic is C, 55° is D, 35° is V, 90° square is S, 60° triangle is T, the three-corner 80° trigon is W.
  3. Look at the faces. A hole or no hole, a chipbreaker groove on one face or both, fixes the fourth letter. Whether the edge sits flat (0°, letter N) or the faces slope away (positive clearance) fixes the second.
  4. Assemble and check. Build the code, then check every digit against the size chart before ordering. If letters are worn away or two digits stay uncertain, do not guess the order — send photos instead (next section).

Code worn or partly unreadable?

Where the tables stop — worn letters, a maker suffix, a shape you cannot settle — the photo identification service reads the insert from photos instead: shape, size class and chipbreaker style from the geometry, with the limits of a photo reading stated up front.

What the ISO code does NOT tell you

Everything after CNMG120408 — the two-letter suffix (such as -MA, -PM, -TM) and the grade name — is manufacturer-specific. The suffix is the chipbreaker geometry, the grade is the carbide substrate plus coating recipe. There is no ISO table that converts one maker's grade into another's; anyone who gives you a conversion chart is giving you a starting point for a trial, not an equivalence. This is exactly why the same CNMG120408 from two suppliers can behave like two different tools: the ISO part is identical, the chipbreaker and grade are not.

When you ask for a quote, quote the full string: ISO code + chipbreaker suffix + grade (or the material group it should cover: P steel, M stainless, K cast iron). Quotes you receive back are only comparable when all three parts match your request.

The other code on the box: ISO 513 material and application groups

The code decoded above (ISO 1832) describes the insert itself — its shape, size and tolerance. A second, shorter code often printed on the same box describes something else entirely: what the insert is made of, and which workpiece material it is meant to cut. That system is ISO 513, and it reads as two material letters, a dash, a group letter and a number — for example, HC-K20 is a coated carbide classified for cast iron, application group 20. If your box carries a line like that, this section reads it.

The two material letters

The first letter names the cutting-material family: H for carbides, C for ceramics, D for diamond, B for cubic boron nitride. The second letter names the subdivision inside the family.

One trap for readers of the shape code: the letter H does double duty. As the first material letter it means carbide; as an application group below it means hard materials. The position tells you which — before the dash it is the material, after the dash it is the workpiece group.

The group letter and number after the dash

The application group classifies the workpiece material the cutting material is intended for. Each letter carries an identification colour, the same six groups used across this site:

GroupColourWorkpiece materials
PBlueSteels and steel castings — long-chipping
MYellowStainless steels
KRedCast irons — short-chipping
NGreenNon-ferrous metals (aluminium, copper alloys)
SBrownHeat-resistant super alloys and titanium alloys
HGreyHard materials — hardened steel, hardened and chilled cast iron

The number after the letter positions the grade inside the group. Groups are numbered from the finishing end upward — P01 to P50 in the steel group, for example. A low number means the classification leans toward wear resistance: lighter, more stable cuts at the finishing end. A high number leans toward toughness: heavier, interrupted, less stable cuts at the roughing end. So HC-P10 and HC-P40 are the same kind of tool material aimed at opposite ends of the same group's work.

Read one in full: HC-P25

HC — coated carbide. P — the steel group. 25 — the middle of the group's range, the general-purpose position. That is a complete ISO 513 reading, and it is also where the code stops. An application group is a classification, not a grade name: every maker assigns its own commercial grades into these groups, and two makers' grades sitting in P25 are not the same product — their composition, coating and chipbreaker still differ. That is why a box code from another supplier starts a matching check rather than finishing one: send the full line from your label, and the grade direction for your material and operation is confirmed against it before quoting, the same confirmation described in our workpiece material groups guide.

FAQ

Can I identify an insert from the code alone if the markings are worn off? The code is what is worn off — identification then works in reverse: measure the inscribed circle and thickness with a caliper, identify the shape and corner angle, and check the chipbreaker form. Our free photo identification service does exactly this from three photos.

Is a G-class insert always better than M-class? No. G costs more because it is ground to tighter tolerance. For roughing and most general turning, M is the rational choice; for finishing passes and boring where you swap edges without touching offsets, G earns its price.

My current insert is from a major brand. Can a different maker's same ISO code replace it? Geometrically it follows the same nominal dimensions — but confirm the seat and tolerance class before treating it as a drop-in replacement. Cutting behaviour depends on the chipbreaker and grade, which are maker-specific, so treat the first order as a structured trial: same workpiece, same parameters, count parts per edge.

Can I swap a CNMG for a WNMG? Only with a holder check. WNMG gives 6 usable edges against CNMG's 4, which is its whole economic point, but it needs its own holder seat. We compare the two, including holder fit, in our CNMG vs WNMG guide.

What does the suffix after the code, like -MA or -PM, mean? It is the manufacturer's chipbreaker geometry — maker-specific, not an ISO position. Two inserts with the same ISO code and different suffixes can cut very differently, so never drop the suffix from a quote request.

Does the ISO code tell me the grade or coating? No. The grade name after the code is the maker's substrate-plus-coating recipe, and there is no ISO table converting one maker's grade into another's. A conversion chart is only a starting point for a trial.

Why do two suppliers' CNMG120408 inserts perform differently? Because the ISO part is identical and the maker-specific part is not: chipbreaker geometry and grade decide chip control, edge strength and wear. Same code, same holder, different cutting behaviour — which is why the first order should be a scored trial, not a price comparison.

What should I put in a quote request? The full string: ISO code + chipbreaker suffix + grade, or the material group it must cover (P steel, M stainless, K cast iron). Quotes are only comparable when all three parts match your request.

How do I read a code I have never seen? Read it position by position from the table above: shape, clearance, tolerance, fixing/chipbreaker, size, thickness, nose radius. If the markings are worn off, measure the inscribed circle and thickness and use our photo identification service instead of guessing.
